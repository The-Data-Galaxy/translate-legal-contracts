# 最小公开演示

使用根README中明确标为虚构的人民币100元条款，展示对应英文及条件/例外保留；不要复制内部猎头合同的当事人、账号、条款或页面。

可运行演示采用tests/中的临时合成OOXML：执行正常构建/audit，检查输入字节未改变；执行路径碰撞和继承编号变化的负向用例，展示拒绝或核查失败。公开命令见TESTS.md。

说明已填写的translations映射来自Agent翻译；Python脚本本身不翻译。演示不宣称机器法律准确率、不把结构通过展示为真实页面验收，也不宣传未经验证的宿主或复杂文档支持。

本计划仅复用已有文本与合成测试，不新增渲染、视频、模型调用或批量测试。
